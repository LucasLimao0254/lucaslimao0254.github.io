# lucaslimao0254.github.io

Raiz do GitHub Pages. Serve só a verificação de domínio do app Android
**Calculadora de Reajuste** (`.well-known/assetlinks.json`), que permite ao APK abrir
https://lucaslimao0254.github.io/Calculadora-combustivel/ em tela cheia, sem barra de endereço.

O arquivo é gerado no repositório
[Calculadora-combustivel](https://github.com/LucasLimao0254/Calculadora-combustivel) por
`npm run android:assetlinks`. O `.nojekyll` faz o GitHub Pages publicar a pasta `.well-known`.
